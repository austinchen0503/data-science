### 💧 [Reservoir Water Quality Database](./water-quality-database)

Object-oriented tool that pulls reservoir water quality readings from Taiwan's
open data API into SQLite, flags each record for completeness, and answers three
questions in SQL — threshold exceedances, per-reservoir means, and the share of
stations with no reading at all.

**Skills:** Python, SQLite, SQL aggregation, API ingestion, data quality checks
